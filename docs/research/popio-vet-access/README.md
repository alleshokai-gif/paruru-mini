調査日: 2026-08-24（Asia/Tokyo）  
対象: 川崎市宮前区神木本町2丁目を代表地点とした車移動  
状態: 公開情報の調査スナップショット。診療受付・担当医・保険・夜間枠は受診前に電話で再確認する。

## 先に結論

「一院ですべてを賄う」のではなく、次の4層で持つのが安全である。

| 役割 | 第一候補 | 第二候補・補完 | 選定理由 |
|---|---|---|---|
| 日常のホームドクター | みやまえだいら動物病院 | 鈴木ペットクリニック | 前者は現体制の公式情報、日祝診療、X線・超音波、説明面の最近の口コミが比較的そろう。後者は神木本町から約2分、iPet、原則年中診療で日常アクセスが非常に強い |
| 休日・夜間・緊急 | 川崎市獣医師会 夜間動物救急センター（20:00–23:30） | アニマルメディカルセンター（24時間）／青葉どうぶつ医療センター（指定曜日の深夜帯） | 夜間救急は近いが入院不可。入院や時間帯外の代替先を別に保持する |
| 整形・神経 | 青葉どうぶつ医療センター | ルート動物病院／横浜青葉どうぶつ病院 | 青葉は整形・神経・椎間板疾患の内外科とリハビリを公式確認。ルートは近隣で椎間板・整形手術の記載あり |
| 高度医療・二次診療 | 日本動物高度医療センター川崎本院（JARMeC） | ホームドクターからの紹介経路を事前確認 | 神木本町から約14分。紹介制で脳神経科・整形科・CT・MRI・ICU等を公式確認。救急外来ではない |

ホームドクターは公開情報だけで最終決定せず、まず「みやまえだいら」と「鈴木」を各1回受診し、説明、料金提示、子犬の扱い、椎間板症状時の紹介基準を同じ質問で比較するのがよい。整形・神経の緊急症状では、通常のランキングではなく、当日の受付可否を電話確認して役割別候補へ接続する。

これは獣医師の診断や個別の医療助言ではない。歩けない、強い痛み、呼吸困難、けいれん、意識状態の異常などがある場合は、Web情報の比較より先に病院へ電話する。

## 調査方法と証拠の分離

### 公式・一次情報

- iPet: 窓口精算対応の判定
- 各病院公式サイト、川崎市獣医師会、日本動物高度医療センター: 診療時間、設備、専門領域、紹介・夜間体制
- 国土地理院住所検索: 緯度経度（町丁目・街区相当の概略値）
- Google Maps経路: 神木本町2丁目代表地点からの距離・車移動時間

### 口コミ

- Google Maps: 評価、件数、公開表示された最近・関連度順レビューの傾向
- Calooペット: 表示スコア、件数、公開レビューの傾向
- EPARKペットライフ、Doctors File等: 取得できた施設のみ第三ソースとして補助

レビュー本文は転載データベース化していない。公開画面で確認できた内容を短く要約し、投稿日・分類・URLを保持した。取得困難なサイトへの自動スクレイピング、ログイン回避、robots.txt回避は行っていない。

### Cross-source Signal

- 同じ論点が2ソース以上で再現した場合のみ `replicated` とした。
- 単独の医療上の重大な申告は、事実認定せず `single_source_medical_concern` として残した。
- 待ち時間、受付、電話、費用と、診断・治療・緊急対応を分離した。
- 高度医療・夜間施設は重症例が集中するため、低評価を一次病院と同じ意味では扱っていない。

## Local Reputationの扱い

今回、実在するLocal Signalは提供されていない。依頼文中の「鈴木ペットクリニックはママ友コミュニティで評判が良くない」は説明用の例であり、データには登録していない。

将来の近隣住民・犬仲間・トリマー・実受診経験は、公開病院データと混ぜず、次の形で個人用オーバーレイへ保存する。

```json
{
  "hospital_id": "suzuki-pet-clinic",
  "observed_at": "YYYY-MM-DD",
  "source_type": "dog_friend",
  "claim": "何についての評価かを具体的に記録",
  "status": "hypothesis_only",
  "medical_quality_effect": 0,
  "storage_class": "private_user_observation"
}
```

ぽぴおの診療内容、飼い主情報、実受診メモ、Local Signalの提供者情報は通常のGitへ入れない。公開可能な病院基礎情報と、個人・健康情報の保存先を分離する。

## スコア式

全スコアは0–100の参考値で、未知項目を肯定扱いしない。最終推薦の自動決定には使わない。

### Accessibility Score

- 車時間 40点: 5分以下40、10分以下34、15分以下28、20分以下20、30分以下10、それ以上4
- iPet窓口精算 20点: 対応20、非対応0、不明5
- 駐車場 15点: あり15、なし0、不明5
- 日曜 10点、祝日 10点
- 予約・受付導線 5点: Web 5、電話3、来院順2、不明0

### Home Doctor Score

`0.35×Accessibility + 0.20×説明・対話 + 0.15×日常診療 + 0.10×継続性 + 0.10×iPet + 0.10×紹介体制`

説明・対話と継続性は口コミを使うが、件数、鮮度、複数ソース再現性により上限を調整した。

### Emergency Score

- 深夜30、時間外・救急20、土日祝15、当日受付10、入院10、X線・超音波10、CT/MRI 5
- 「夜間」でも受付時間限定や曜日限定は減点。夜間救急の入院不可も反映した。

### Dachshund Score

- 整形20、神経20、椎間板疾患の公式記載20、手術15、X線・超音波10、CT/MRI 10、リハビリ5

### Medical Capability Score

- 診療チーム15、入院10、手術15、X線5、超音波5、CT15、MRI15、紹介10、救急10

### Overall reference

`0.30×Home Doctor + 0.20×Emergency + 0.25×Dachshund + 0.15×Medical Capability + 0.10×Accessibility`

総合点は役割の異なる施設を同列に並べる弱点がある。JARMeCや夜間救急は総合点ではなく、その役割のスコアで選ぶ。

### Reputation Confidence

- Google件数40点
- Caloo・第三ソースの有無20点
- 最近の口コミ20点
- Cross-source一致20点

表示スコアの良し悪しではなく、「評判判断に使える証拠量」の指標である。Calooの表示値は単純平均とは限らないためGoogleと平均していない。

Bayesian Averageは今回は算出していない。地域全体の同一ソース・同一時点の母平均と十分な施設サンプルを固定せずに計算すると、もっともらしいだけの補正値になるためである。将来導入する場合も、Google内・Caloo内で別々に `adjusted = (v/(v+m))×R + (m/(v+m))×C` を計算し、異なるサイトの値は平均しない。`C` は同一地域・同一取得日の母平均、`m` は事前に公開した最小信頼件数とする。

Googleの全レビュー分布や★1/★5比率は公開画面から規約に反しない形で完全取得できていない。このため極端評価比率はスコア入力にせず、確認できた具体的な本文傾向と複数ソース再現性だけを使った。

## 初診時に共通して確認する質問

1. ミニチュアダックスの子犬で、腰痛・歩行異常・麻痺が疑われる場合の当日診療手順
2. X線・超音波を院内で行えるか。CT/MRIが必要な時の紹介先と当日連携の可否
3. JARMeC川崎本院へ紹介した実績と、休診日・夜間に紹介状や画像を渡す方法
4. 去勢手術の麻酔前検査、術中監視、入院・帰宅基準、総額見積り
5. iPet窓口精算の対象外になりうる処置・時間外費用
6. 夜間急変時に最初に電話する施設、翌日の診療情報引継ぎ方法
7. 予約患者と救急患者の優先順位、当日枠、待ち時間の目安

## PALURU連携と将来のWeb表示

Schemaは [hospitals.schema.json](hospitals.schema.json) にある。PALURUへは、公開病院データをRead-onlyのDomain Serviceから返し、個人の受診履歴やLocal Reputationを同じJSONへ直書きしない。

スマホ画面はランキングではなく、入口を役割で分ける。

```text
ぽぴお病院MAP
├─ いつもの病院
├─ 今日診てもらえる（曜日・時刻と最終確認日時を表示）
├─ 日曜・祝日
├─ 夜間・緊急（電話確認を先に表示）
├─ 整形・神経・椎間板
└─ 高度医療（紹介制かどうかを明示）
```

病院カードには「電話」「Google Maps」「公式サイト」「本日の公表診療時間」「役割」「入院可否」「紹介制」「注意点」「最終確認日」を表示する。`今日診てもらえる` は公表時間だけで断定せず、「受付可能性あり／要電話確認」と表示する。今回は表示実装やAPI変更は行っていない。
