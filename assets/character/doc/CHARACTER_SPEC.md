# PALURU Official Character Generation Specification v1.0

## Purpose

Generate the official mascot character "Paluru" for the PALURU platform.

The attached character sheet is the **official design reference**.

It defines the character's identity and personality.

Do NOT reproduce or redraw the character sheet itself.

Instead, create a brand-new illustration that faithfully preserves the same character.

---

## Reference

Use the attached image only as a design reference.

Preserve the following characteristics.

## Expression

This is the most important part.

Paluru should NOT look overly cheerful.

Facial expression should communicate:

> "I'm not worried or anything... but I'll take care of it."

Requirements:

- sleepy half-lidded blue eyes
- eyebrows slightly raised in an "eh..." expression
- very small smile
- mouth corners lifted only a little
- relaxed face
- soft blush

Never use:

- huge smile
- surprised expression
- exaggerated anime emotions

---

- hair direction identical to the reference

Front facing.

## Quality

The illustration should feel like an official mascot from a commercial software company.

Think:

- Slack mascot quality
- Discord mascot quality
- LINE Friends quality

Not:

- generic AI cat
- random anime character
- over-detailed fantasy illustration

## Important

The attached reference image is **NOT** the final artwork.

It defines the character only.

Generate a completely new illustration while preserving the identity.

Do not copy the reference.

Create a new official illustration that looks like the same character.
