# 小田急乗換 PoC 実装前記録

目的: 本番を変更せず、公式に利用できる取得経路と実データの限界を明示した縦型UI・乗換比較を作る。
証拠: 2026-10-27 JST のODPT取得でStationTimetable=276、Station=72、Railway=3、Train=0、TrainTimetable=0。駅時刻表に列車番号・着時刻なし。
方針: 既存BUSの認証分離、HTTP timeout、入力検証、生成時刻保持、allowlist配信を再利用する。同一便は確定できないため、時刻表の種別・行先・停車順を使った一意候補のみ仮説として表示し、曖昧なら途中で打ち切る。実測位置、着時刻、乗換推奨に昇格させない。
影響範囲: poc/odakyu/のみ。GAS/Cloud Run/GCS/本番PWA/Service Worker変更なし。
副作用: 手動collector実行時にODPT readとローカル保存。自動pollingなし。非公開API、公式サイト情報の無許可二次利用なし。
ロールバック: ローカルserver停止、独立branchを不採用にする。既存本番変更なし。
受入: 異時点保存・再読込とhash、実データ由来の表示、参考比較、曖昧性・着時刻欠落・通過駅・乗換bufferの安全制御、360/390px実ブラウザ。
ライセンス: ODPT challenge限定、2027-03-12終了予定。恒久利用許諾でない。raw/派生データをGitへ入れず、ローカル開発用途。公開・継続運用には応募目的/条件の適合確認が必要。小田急公式リアルタイムサイトは無断二次利用禁止のため取得実装しない。
