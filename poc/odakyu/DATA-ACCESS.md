### 小田急向け

件名：個人用ローカル列車乗換ナビにおける時刻表データ利用条件の照会

小田急電鉄 データ利用ご担当者様

新宿・代々木上原方面から登戸・向ヶ丘遊園へ向かう際に、乗車列車の継続と途中乗換を比較する、非公式の個人用ローカルアプリを検討しております。現時点でサービス公開・課金は行わず、無断の継続取得は実装しておりません。

列車単位の便識別子、種別、停車・通過、駅別着発、適用日・改正日を、正規の提供方法で利用できるでしょうか。千代田線直通の同一列車対応と種別変更も対象です。次の条件について、ご担当窓口または必要な申請をご案内ください。

1. 個人の端末内での取得・保存・加工・先着比較・表示の可否、および既存保存資料の利用条件
2. 公式API・データファイル・契約提供元の有無、取得頻度と保存/キャッシュ期限
3. 将来の非営利外部公開が可能か、必要な表示・免責・契約・料金
4. 適用日・改正/運休の更新方法と利用終了時の対応

外部公開の許諾と個人ローカル利用の許諾を分けてご回答いただければ幸いです。回答いただくまでは新規の継続スクレイピング・未許諾データの再配布は行いません。

### ODPT事務局向け

件名：小田急列車単位時刻表とチャレンジ終了後の個人ローカル利用について

公共交通オープンデータ協議会事務局 御中

小田急の駅時刻表を用いた静的乗換比較のローカルPoCを検討しております。小田急の列車単位時刻表、登戸・向ヶ丘遊園の着時刻、便ID/運転列車番号、千代田線直通の継続IDについて、提供中または申請可能なデータはありますでしょうか。

チャレンジ限定ライセンスについて、個人用ローカルPoCの目的適合に必要な手続き、2027年3月12日以降の恒久利用・更新を可能にする別ライセンス、既存保存データの扱いをご教示ください。再利用可能な元データや派生DBを外部配布する計画はありません。申込・契約・利用目的登録が必要な場合は、その窓口と条件をお願いいたします。

### NAVITIME向け

件名：個人ローカル乗換比較向けの小田急列車時刻表API利用相談

NAVITIME API ご担当者様

新宿・代々木上原から登戸・向ヶ丘遊園への継続乗車/途中乗換を比較する非公式の個人用ローカルアプリを検討しています。列車単位の同一便ID、駅別の着時刻・発時刻、停車/通過、千代田線直通時のID対応と種別変更、適用日・改正情報が必要です。

時刻表データ利用オプションの対応項目、個人契約の可否、費用、取得回数制限、ローカル保存/キャッシュ期限、独自エンジンによる先着比較の可否をご案内ください。将来の非営利公開は別途条件を確認し、現段階では申し込み・課金・外部公開を行いません。公式Webの表示用データを転用せず、契約に適合する方法を希望しています。
